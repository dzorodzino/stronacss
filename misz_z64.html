Zaokrąglanie narożników i centrowanie DIV

__________Początek teorii zaokrąglanie narożników _______

Zaokrąglenie narożników obszarów bloków np. DIV

Zaokrąglenie górnego-lewego narożnika:
selektor { border-top-left-radius: zaokrąglenie }

Zaokrąglenie górnego-prawego narożnika:
selektor { border-top-right-radius: zaokrąglenie }

Zaokrąglenie dolnego-prawego narożnika:
selektor { border-bottom-right-radius: zaokrąglenie }

Zaokrąglenie dolnego-lewego narożnika:
selektor { border-bottom-left-radius: zaokrąglenie }

Zastosowanie:

We wszystkich przypadkach selektorem może być dowolny znacznik, np.:

  • p – akapit
  • h1 – nagłówek
  • div – blok

„zaokrąglenie” określa promień wyrażony w jednostkach długości albo w procentach. Możliwe jest podanie jednej lub dwóch wartości (poziomej i pionowej).

Zaokrąglone narożniki poprawiają estetykę strony. Element nie musi mieć obramowania, aby efekt był widoczny – wystarczy tło. Tekst nie dopasowuje się do zaokrągleń.

Przykład: border-top-right-radius: 10px
