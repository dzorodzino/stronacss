1. Co to są pseudoklasy?

CSS przewiduje kilka ściśle określonych klas pozwalających na formatowanie niektórych elementów dokumentu. Są to pseudoklasy.

2. Uwaga dotycząca dwukropka

Szalenie istotnym elementem tej konstrukcji jest dwukropek (:) występujący pomiędzy selektorem a nazwą pseudoklasy.

3. Tabela opisująca pseudoklasy

Pseudoklasa Opis
A:link Odpowiada za wygląd hiperłącza, jeżeli nie zostało ono jeszcze odwiedzone.
A:visited Odpowiada za formatowanie hiperłącza już odwiedzonego.
A:hover Zmiany elementów po najechaniu na nie kursorem myszy.
A:active Formatowanie aktywnego (klikniętego) odsyłacza.
A:focus Formatowanie elementu posiadającego fokus.
:lang Formatowanie wielojęzykowych dokumentów.
:first-child Pozwala określić formatowanie pierwszego dziecka wybranego elementu.

4. Zastosowanie pseudoklasy :active

1. Można używać jako uzupełnienia definicji odnośników.
2. Może poprawiać czytelność formularzy.

5. Przykłady kodów definiowania pseudoklas

Przykład 1 - :link oraz :visited

A:link
{
    color:red;
}

A:visited
{
    color:green;
}

Przykład 2 - Formatowanie wszystkich odnośników

A
{
    font-size:12pt;
    text-decoration:none;
}

A:link
{
    color:navy;
}

A:visited
{
    color:green;
}

A:hover
{
    color:red;
    text-decoration:underline;
}

Przykład 3 - Zastosowanie :focus

A:focus
{
    color:brown;
}
