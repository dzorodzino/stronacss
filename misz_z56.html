1. Składnia teoretyczna definiowania klasy

    selektor.klasa { cecha: wartość }

  2. Podaj opis dla Klasa "cecha" oraz "wartość"

    Klasa to wartość atrybutu class przypisana do elementu HTML. "cecha" oraz "wartość" określają właściwości formatowania elementu nadane za pomocą CSS.

  3. Jaki znacznik może być selektorem?

    Selektorem może być dowolny znacznik HTML, np.:
    • p – akapit
    • h1 – nagłówek
    • td – komórka tabeli

  4. Uwagi na temat nazwy klas

    Nazwą może być dowolny pojedynczy wyraz, nie może on zawierać:
    • spacji
    • kropki
    • przecinka
    • dwukropka
    • znaku zapytania
    • nawiasów
    • znaku równości
    • plusa
    Może zawierać:
    • litery
    • cyfry
    • myślniki
    • podkreślniki
    Nazwa nie może zaczynać się od cyfry ani myślnika. Gdy chcemy użyć znaków zakazanych należy poprzedzić je ukośnikiem odwrotnym \.

  5. Jakie jest zastosowanie klas?

    Klasy służą do nadawania określonego stylu wybranym elementom strony bez konieczności formatowania wszystkich elementów tego samego typu.

  6. Kiedy ma zastosowanie lista klas?

    Gdy chcemy przypisać jednemu elementowi kilka różnych klas jednocześnie.

  7. Składnia listy klas oraz uwagi

    <selektor class="klasa1 klasa2 klasa3">...</selektor>
    Uwagi:
    • Klasy muszą być wcześniej zdefiniowane.
    • Kolejność klas nie ma znaczenia.
    • Obowiązuje zasada kaskadowości CSS.

  8. Podzbiory klas

    selektor.klasa1.klasa3 { cecha: wartość }
    Podzbiór klas oznacza, że element musi posiadać jednocześnie wszystkie wskazane klasy.

  9. Co jest sygnałem, że należy zastosować klasy?

    Jeżeli dany element występuje wielokrotnie na różnych stronach i powinien mieć takie samo formatowanie.

  10. Kiedy powinny być planowane klasy?

    Już na etapie projektowania strony internetowej, aby późniejsze modyfikacje były łatwiejsze.

  11. Jaki jest cel stosowania komentarzy?

    Komentarze opisują przeznaczenie klas i ułatwiają późniejszą pracę z arkuszem stylów.

  12. Przykład definiowania klasy i użycia

    p.przyklad_klasa { color:red; }
    Wywołanie:
    <p class="przyklad_klasa">To jest akapit.</p>

  13. Klasa odnosząca się tylko do jednego selektora

    Przykład:
    p.moja { color:green; font-size:14pt; }
    Wywołanie:
    <p class="moja">Treść akapitu</p>

  14. Cel stosowania klasy uniwersalnej

    Klasa uniwersalna może być używana przez różne znaczniki HTML. Definicja:
    .przyklad_uniwersalna { color:red; font-size:12pt; }
    Wywołanie:
    <p class="przyklad_uniwersalna">Akapit</p> <h1 class="przyklad_uniwersalna">Nagłówek</h1>
    Znak * oznacza selektor uniwersalny i może zostać pominięty.
